README for armed_conflict repository for CHL5233 course work. 
This repository contains files to reproduce the analysis from the armed conflict paper. 

- September 28th: A Quarto file quarto_inclass was created and saved as a PDF, answering questions about countries, regions, and subregions within 2 datasets. The final product for this week was to create a bar chart depicting how many countries were in each region.
- October 5th: An R script was added to "scripts" creating a final data set based off the armed conflict paper. World bank data, disaster datasets, and conflict data were all cleaned and merged together based of the week 3 instructions. Finally a csv file of the final data was added to "data/processed" in the repository. This file was then recreated by codex but not included here. Codex originally kept all rows with disaster data even those with missing covariate and mortality data, whereas my dataset obmitted those rows.
